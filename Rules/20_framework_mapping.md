# Framework Mapping & Source Notes

The rule pack uses the following sources as its baseline. Re-check framework versions and legal applicability before each audit cycle.

| Source | Role in rule pack |
|---|---|
| OWASP ASVS 5.0.0 | Main application-security control backbone. |
| OWASP WSTG | Testing methodology and structured web-security test approach. |
| OWASP API Security Top 10 (2023) | API authorization, resource consumption, sensitive business flows, SSRF, configuration and inventory risks. |
| OWASP Automated Threats | E-commerce abuse taxonomy: credential attacks, carding, scalping, scraping, denial of inventory, etc. |
| PCI DSS v4.0.1 | Payment account-data security and assessment boundary. |
| GDPR | EU personal-data governance, rights, security and accountability. |
| EU DSA | Online-platform/marketplace obligations including trader transparency and redress where applicable. |
| WCAG 2.2 | Accessibility success criteria; automated testing must be combined with human evaluation. |
| NIST CSF 2.0 | Cybersecurity governance/risk-management structure. |
| NIST SP 800-61 Rev. 3 | Incident-response structure. |
| India DPDP Act/Rules | India digital personal-data obligations and phased implementation. |
| CERT-In Directions | Indian incident reporting/logging requirements where applicable. |

## Current-source verification
OWASP lists ASVS 5.0.0 as its latest stable version. WSTG is a comprehensive testing guide. OWASP API Security Top 10 2023 includes BOLA, broken authentication, property/function authorization, unrestricted resource consumption, sensitive business flows, SSRF, security misconfiguration, inventory management and unsafe API consumption. WCAG 2.2 is a W3C Recommendation. NIST CSF 2.0 is the current NIST cybersecurity framework.
